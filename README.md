# Projet 1 : Déboguez une application .NET

Ce projet est une **correction d'un site web développé en .NET**, dans le cadre de ma formation "Développeur d'application back-end .NET".  
Il est basé sur un projet existant mais modifié dans une branche dédiée à ma version contenant mon travail final qui était d'implémenter les TODO du projet.

---
## Les TODO réalisés

- Ajout des articles dans le panier 
- Calcul du total des articles dans le panier
- Calcul de la moyenne des articles dans le panier
- Mise à jour des stocks après commande
- Recherche d’un produit spécifique dans le panier
- Recherche des articles dans le panier par l’ID
- Changer le type de retour de GetAllProducts() en List <>
- Changement de langues (Anglais/Espagnol)

---
## Outils et technologies utilisés

- **Visual Studio 2022**
- **C# / ASP.NET Core**
- **Git & GitHub**

---
## Cloner le dépot via Git Bash et l'exécuter

*Mon rendu se trouve dans la branche `dev`.*

Pour consulter ou exécuter ma version, il faut cloner le dépôt avec cette branche directement :

```bash
git cd [emplacement souhaité pour y copier le projet]
git clone -b dev https://github.com/khiastos/Projet-2-OC.git
```

- Ouvrir Visual Studio
- Sélectionner "Ouvrir un projet ou une solution"
- Ouvrir le fichier qui termine par .sln dans le projet cloné
- Sélectionner comme élément de démarrage "P2FixAnAppDotNetCode" (Clic droit sur "P2FixAnAppDotNetCode" → “Définir comme projet de démarrage”)
- Exécuter l'application
